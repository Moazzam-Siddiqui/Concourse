# Extra dependencies for the layout → graph pipeline (ai-service/app/layout).
# Kept separate from requirements.txt on purpose: the core AI service still has
# zero heavyweight dependencies, and /analyze must keep working if none of this
# is installed. The layout endpoints degrade instead of the service failing.

# --- always needed for the pipeline (CPU only, no VRAM) ---
opencv-python-headless>=4.10
numpy>=1.26
scikit-image>=0.24
python-multipart>=0.0.9     # FastAPI file uploads
Pillow>=10.4

# Label reading (rapidocr) lives in requirements-ocr.txt, not here. It pulls the whole
# ONNX runtime, which is the largest single thing this service would load, and app/layout/
# ocr.py already imports it inside a try/except: without it the pipeline traces the plan
# from geometry alone and logs "plans will trace without labels".
#
# That split is what lets the service fit a 512MB instance. Tracing works; only the
# reading of printed labels needs the extra install.
